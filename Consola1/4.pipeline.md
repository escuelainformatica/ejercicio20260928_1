# Azure devops pipeline

* Cree el siguiente archivo azure-pipelines.yml en la raiz del proyecto, que es un archivo de azure pipeline
* Agregue los siguiente pasos al pipeline:
  * Paso 1: Restaurar paquetes de NuGet
  * Paso 2: Compilar la solución
  * Paso 3: Ejecutar pruebas unitarias
  * Paso 4: Publicar resultados de pruebas unitarias
  * Paso 5: Ejecutar pruebas de integracion
  * Paso 6: Publicar resultados de pruebas de integracion
  * Paso 7: Ejecutar pruebas de seguridad
  * Paso 8: Ejecute cobertura de código y publique los resultados de cobertura de código
* Especifique usar Ubuntu (ubuntu-22.04) como sistema operativo para el agente de compilación
* Considere lo siguiente:
	* Para hacer las pruebas de la aplicación de consola, es necesario que la aplicacion de WebAPI este corriendo, por lo que se debe agregar un paso para ejecutar la WebAPI antes de ejecutar las pruebas de integracion y de seguridad.
	* La aplicacion de WebAPI debe ejecutarse en segundo plano, para que las pruebas de integracion y de seguridad puedan ejecutarse mientras la WebAPI esta corriendo.
