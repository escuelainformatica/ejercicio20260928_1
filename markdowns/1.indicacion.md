# informacion del proyecto

## proyecto Consola1
Un proyecto de consola, que se conecte al proyecto de web api, y devuelva el total de carro de compras.
Ademas, con el total de carro de compras, aplique el IVA que es multiplicar el total por 1.19


## proyecto WebApi1
Cree un proyecto de WebAPI, que devuelva un listado de carro de compras.
El listado de carro de compras, debe leerse desde un archivo json llamado "carro.json". Si uno esta
creelo con datos de ejemplo.

## Modelo

* Carro de Compras: CarroCompra
   * Id (entero y autonumero)
   * NombreProducto (texto)
   * Cantidad (entero)
   * PrecioUnitario (entero)
   
## proyecto Libreria1
Cree un proyecto de libreria que tenga el modelo de los otros proyectos, y las clases de servicio.
   
## proyectos de pruebas
Cree dos proyectos de pruebas unitarias y de integracion llamado ConsolaTest1 y WebApiTest1
Use xunit para las pruebas unitarias y de integracion. En el proyecto de pruebas unitarias, cree pruebas unitarias para los servicios de la libreria. En el proyecto de pruebas de integracion, cree pruebas de integracion para la WebAPI y la Consola.

## proyecto de seguridad
Cree un proyecto de pruebas de seguridad llamado SeguridadTest1, que tenga pruebas de seguridad para la WebAPI y la Consola. Use xunit para las pruebas de seguridad.
